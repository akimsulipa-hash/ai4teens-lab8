# AI4Teens 🤖

**AI4Teens** — освітня ІТ та AI-платформа для підлітків, яка допомагає знайомитися зі штучним інтелектом, програмуванням і цифровими технологіями через практику та цікаві проєкти.

> Lab 8 · навчальний репозиторій

---

## 📖 Про проєкт

AI4Teens створений для того, щоб пояснювати складні речі про AI простою мовою та давати підліткам змогу самостійно створювати працюючі проєкти. Платформа поєднує теорію, практичні завдання та наочні веб-інтерфейси.

### Мета
- Познайомити підлітків з основами штучного інтелекту та машинного навчання
- Розвинути навички веб-розробки та роботи з ІТ-інструментами
- Сформувати критичне мислення щодо можливостей і обмежень AI
- Заохотити до самостійних експериментів і проєктної роботи
